# Thư viện luật chuẩn (rules/L-xxx.md)

Thư mục chứa các luật chuẩn áp dụng khi giao việc cho AI trong dự án AITeam.
Mỗi file có định dạng `L-xxx.md` với metadata (Trạng thái, Loại việc, Bước, AI, Nguồn, Ngày) và nội dung markdown.
Luật ở trạng thái Active sẽ tự động được chọn lọc và chèn vào prompt giao việc theo đúng loại việc, bước và AI thực hiện.
