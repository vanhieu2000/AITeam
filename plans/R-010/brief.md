# Brief R-010 — Bộ skill cho từng bước dây chuyền (Codex soạn nội dung)
- **Mục tiêu:** mỗi bước có 1 skill ngắn, chuẩn hóa cách làm ⇒ AI nào làm bước đó cũng làm giống nhau, task nhỏ ít sai. Sau mỗi lần đánh giá / IMP, lỗi mới được ghi vào skill tương ứng ⇒ càng chạy càng tốt.
- **Vị trí:** `skills/` trong repo AITeam (dùng chung mọi dự án, có trên mọi máy qua git). 1 thư mục / skill: `skills/<id>/SKILL.md` (≤ 150 dòng): Mục tiêu · Đầu vào · Đầu ra (định dạng) · Các bước · Checklist bắt buộc · Lỗi hay gặp (có nguồn: IMP-xxx / task) · Ví dụ ngắn tốt / xấu.
- **Skill theo bước** (khớp trang Map R-009): `01-tiep-nhan` · `02-y-tuong` · `03-research` · `04-ke-hoach` · `05-duyet-ke-hoach` · `06-chuan-bi-task` · `07-code` (chung) · `08-kiem-thu` (cổng KT + test nghiệm thu) · `09-qc` · `10-nghiem-thu` · `11-publish-git` (merge, clone sạch, push, không force-push main, repo private).
- **Skill code (trọng tâm, nghiên cứu kỹ):**
  - `code-winforms`: tóm lược từ `%USERPROFILE%\.claude\skills\winforms-expert\SKILL.md` + quy ước THẬT trong dự án HDVTool / ChinaAndroidToolbox (TableLayoutPanel / FlowLayoutPanel, DPI 100–200 %, MinimumSize, chuỗi dài, test UI luồng STA / helper UiThread, không mở form thật trong test nền, LayoutChecker / UiSnapshot), lỗi đã gặp R-001.
  - `code-web`: ASP.NET Razor Pages + HTMX như Hub (antiforgery, `hx-confirm` trên form, không `Html.Raw`, partial dựng tay ViewData, test dựng trang thật, 1000px không tràn) + tóm lược `create-datadriven-aspnetcore`, `dotnet-webapi`, `author-component` / Blazor khi dự án dùng.
  - `code-app`: .NET MAUI (tóm lược bộ `maui-*`) + app console / CLI (bắt mọi ngoại lệ trong Main, mã thoát, ArgumentList không qua shell).
  - `code-test`: xUnit / test nghiệm thu (tóm lược `scaffold-dotnet-test-project` + AGENTS.md: không return sớm, chuỗi bí mật ghép lúc chạy, tên thiết bị DOS, test tiến trình dùng ProjectReference).
  - Không chép nguyên văn dài; ghi nguồn (đường dẫn skill gốc / file:dòng dự án).
- **Nối vào công cụ:** lời nhắn `plan` / `prep` / giao việc agy / Codex code / `aiteam review` / nghiệm thu tự thêm dòng "Đọc skill: `skills/<bước>/SKILL.md`" + skill code theo `stack` của dự án trong `projects.json` (WinForms ⇒ code-winforms, ASP.NET ⇒ code-web, MAUI ⇒ code-app). Thiếu file skill ⇒ bỏ qua, không lỗi.
- **Tự cập nhật:** lệnh `team.ps1 skill-note -Skill <id> -Text "…" [-Source "IMP-007"]` thêm 1 dòng vào mục "Lỗi hay gặp" (chống trùng, commit). Mẫu IMP + bước nghiệm thu nhắc: lỗi TK / AG / CK mới ⇒ `skill-note`. Trang Map (R-009) hiện liên kết skill của từng nghiệp vụ (nếu task R-009 chưa làm, ghi vào hàng chờ).
- **Chia việc:** soạn nội dung skill = Codex viết (task chỉ đổi `skills/**`, có thể 2–3 task chạy song song); nối công cụ (`team.ps1`, mẫu prompt) = Minh / Lan (chia đều). ≤ 400 dòng / task. **Tiền tố:** S1.
