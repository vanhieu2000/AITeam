# Kho bài học và mẹo (lessons/LS-xxx.md)

Thư mục lưu trữ các bài học, mẹo và đề xuất cải tiến từ quá trình thực hiện công việc.
Mỗi file có định dạng `LS-xxx.md` với metadata (Trạng thái, Loại, Yêu cầu, Task, Bước, AI, Luật, Ngày) và nội dung markdown.
Các bài học ở trạng thái Draft có thể được quản lý xem xét và nâng cấp thành luật chuẩn (Promote) hoặc hủy bỏ (Drop).
